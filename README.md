# Food Rescue Berlin

**What the project is about:** A Spring Boot web app where community fridges track donated food, so neighbours can see what's available and rescue it before it expires.

**Example input:** A volunteer donates "Rye bread, 2 loaves" (1.4 kg, best-before 2026-09-20) into the Wrangelstrasse fridge — this is a donation request sent from the Donate Food form.

**Example output:** The bread appears as an AVAILABLE item in that fridge on the dashboard, and once someone claims it, the "kg rescued" total updates automatically.
